## 👋 Introduction

This workspace contains collections with requests and scripts to help you triage and respond to incidents promptly and effectively. It is designed to be used by incident response teams and other stakeholders to mitigate the problem.

## 🚀 Getting started with this workspace

The collections in this workspace can be used to monitor the health of your systems and swiftly respond to incidents. They are designed to help you automate and streamline your incident response process.

It can be customized to fit the specific needs of your organization and integrated with other tools and platforms as needed.

##### **Environments**

Environments are set up to manage variables like base URLs, API keys, and tokens whose values you can change depending on the context of your work (e.g., development, staging, production).

## ⚙️ Incident protocol

- **Check System Health** - this helps to check the status of your systems.
- **Get System Logs -** retrieves the logs for your service across providers like AWS, New Relic and Datadog.
